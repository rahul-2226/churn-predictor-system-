# Project Report: Customer Churn Prediction System

## 1. Executive Summary
The **Customer Churn Prediction System** is a full-stack, AI-driven platform designed to help businesses proactively identify customers who are likely to discontinue their services. By leveraging Machine Learning (ML), the system analyzes historical customer data to predict churn probabilities and provides actionable insights through a modern, high-performance dashboard.

## 2. Technical Stack
The application is built using a modern, scalable architecture:
- **Backend Framework:** FastAPI (Python 3.13)
- **Frontend:** Vanilla HTML5, CSS3, and JavaScript (ES6+)
- **Machine Learning Libraries:** Scikit-Learn, Pandas, NumPy, Joblib
- **Data Visualization:** Chart.js
- **Icons & UI:** Lucide Icons, Google Fonts (Inter)
- **Server:** Uvicorn (ASGI)

## 3. System Architecture
The system follows a decoupled architecture where the backend serves both as an API provider and a static file host for the frontend.

### 3.1 Backend (FastAPI)
The backend manages the entire data lifecycle:
- **Data Ingestion:** Supports CSV and XLSX file uploads.
- **ML Pipeline:** Automated training and inference logic.
- **API Endpoints:**
  - `POST /api/bulk-predict`: Handles dataset uploads, auto-training, and full-set analysis.
  - `POST /api/predict`: Generates a real-time prediction for a single customer profile.
  - `GET /api/model-info`: Retrieves metadata about the current best-performing model.
  - `GET /api/download`: Generates and exports filtered Excel/CSV reports.

### 3.2 Frontend (Midnight Graphite Dashboard)
The UI is designed with a **"Midnight Graphite"** aesthetic—a high-contrast, premium dark mode.
- **Dynamic Routing:** A single-page application (SPA) feel using custom navigation logic.
- **Interactive Visualizations:** Four distinct charts showing Churn Distribution, Risk Levels, Probability Spread, and Key Risk Factors.
- **Responsive Table:** A filtered data table with risk-level tagging and deep-dive detail views.

## 4. Machine Learning Methodology
The system features an "Automated ML" (Auto-ML) approach to ensure the highest accuracy.

### 4.1 Data Preprocessing
Raw data is passed through a preprocessing pipeline in `src/preprocessing.py` which:
- Cleans missing values (NaN/Inf handling).
- Converts categorical features into numerical formats using `LabelEncoder`.
- Standardizes numerical ranges for improved model performance.

### 4.2 Model Training & Selection
The system trains three distinct classification models simultaneously:
1. **Logistic Regression:** For baseline linear relationships.
2. **Decision Tree Classifier:** For capturing non-linear patterns.
3. **Random Forest Classifier:** For high-accuracy ensemble learning.

**Auto-Selection:** The system compares the accuracy scores of all three models and automatically saves the best-performing one as `models/best_churn_model.pkl`.

## 5. Core Features
- **Real-time Metrics:** Instant updates for Churn Rate, High-Risk Customer counts, and Model Accuracy.
- **Top Churn Drivers:** Derived from model feature importance, identifying the primary reasons customers leave (e.g., "Monthly Charges", "Contract Type").
- **Individual Lookup:** Search for specific customers by ID to see a personalized risk analysis and probability bar.
- **Excel/CSV Exports:** Direct browser downloads for filtered subsets (e.g., "Export only High-Risk customers").

## 6. Installation & Usage
### Prerequisites
- Python 3.9+
- Virtual Environment (`venv`)

### Local Setup
1.  **Clone the project** to your local machine.
2.  **Activate Environment:** `.\.venv\Scripts\activate` (Windows).
3.  **Install Dependencies:** `pip install -r requirements.txt`.
4.  **Run Server:** `python server.py`.
5.  **Access App:** Navigate to `http://localhost:8000`.
